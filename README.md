# SPI Study

Excel問題集から生成した559問を、スマートフォンで反復学習できる静的Webアプリです。React・TypeScript・Viteで構築し、学習記録はブラウザ内に保存します。

## 主な機能

- 4ジャンルから最大50問をランダム出題
- `0 → ★ → ★★` と `☠` の学習状態管理
- 通常問題は50問、★問題は200問の最短再出題間隔
- ☠だけを練習する苦手モード（進捗状態は変更しません）
- 回答ごとの自動保存、途中終了・再開
- 学習記録のJSONバックアップ・復元
- Excelの赤文字補完選択肢を任意で表示
- GitHub Pagesへの自動デプロイ

## 問題データ

対象ファイルは `テスセン問題集v2_未回答補完・要確認色分け.xlsx` です。元のExcelは変更しません。

| シート | 読み込み対象行 | 出題可能 | 除外 | 空行 |
|---|---:|---:|---:|---:|
| 空欄 | 123 | 109 | 13 | 0 |
| 同じ使い方 | 342 | 42 | 38 | 262 |
| 関係 | 99 | 91 | 8 | 0 |
| 熟語選択_類似順 | 345 | 317 | 17 | 10 |
| **合計** | **909** | **559** | **76** | **272** |

除外理由には、黄色の要確認問題75件、選択肢不足、正解が選択肢にない問題、空欄、重複問題が含まれます。理由は重複して数えられるため、理由別件数の合計は除外行数と一致しない場合があります。詳細は `public/validation-report.json` に記録しています。

## セットアップ

Node.js 22以降を使用してください。

```bash
npm install
npm run dev
```

ローカルURLは `http://localhost:5173/q3n8v/` です。

## Excelを更新する

Excelのパスを指定して変換します。

```bash
npm run convert -- "C:\path\to\テスセン問題集v2_未回答補完・要確認色分け.xlsx" public
```

次の2ファイルが更新されます。

- `public/questions.json`: アプリが読み込む問題データ
- `public/validation-report.json`: シート別件数と除外理由

変換時は次を検証します。

- 正解が選択肢にちょうど1つ存在する
- 問題文・正解・選択肢が空欄ではない
- 選択肢が2件以上ある
- 黄色の要確認問題ではない
- 同一内容の重複問題ではない

問題IDはジャンル・問題文・正解・選択肢から生成するため、Excelの行番号が変わっても同じ内容なら維持されます。

## テストとビルド

```bash
npm test
npm run build
```

テストでは状態遷移、☠判定、苦手モード、50問・200問の再出題間隔、50問セッション、二重採点防止、途中記録の復元、Excel見出し判定、不正データ除外を確認します。

## GitHub Pagesで公開する

1. このフォルダの内容を `ymiyatakegi/q3n8v` の `main` ブランチへアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **GitHub Actions** にします。
4. `main` へのpush後、Actionsの `Deploy to GitHub Pages` が完了するのを待ちます。
5. 公開URL `https://ymiyatakegi.github.io/q3n8v/` を開きます。

Viteの `base` はリポジトリ名に合わせて `/q3n8v/` に設定済みです。

## スマートフォンで使う

公開URLをiPhoneまたはAndroidのブラウザで開きます。学習記録はそのブラウザ内に保存されるため、別端末へ移る場合はホーム画面の「記録をバックアップ」でJSONを保存し、新しい端末で「記録を復元」を選んでください。

ブラウザのデータを消去すると学習記録も消えるため、定期的なバックアップを推奨します。
